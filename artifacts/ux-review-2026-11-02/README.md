# StoryMaster — dossier de revue ergonomique

100 captures originales, prises sur ordinateur le 2 novembre 2026. Ouvrir **INDEX.html** dans un navigateur pour la galerie filtrable, ou SOMMAIRE.md pour la liste. Aucun compte externe ni connexion Internet requis pour consulter les images. Le lien vers l’application demande StoryMaster local et sa connexion habituelle.

La galerie commence par les dix vues d’ensemble (091–100). Décocher « Les 10 vues d’ensemble » pour afficher les 100 captures, puis filtrer par fonction ou rechercher un numéro. Cliquer pour agrandir ; flèches gauche/droite pour parcourir ; Échap pour fermer. « Original » ouvre le JPEG en taille native.

## Données de présentation

Projet fictif : **Les Cartographes de brume**, compte de démonstration Alice Martin. Deux manuscrits, quatre chapitres, sept scènes rédigées, trois personnages détaillés, quatre lieux (dont un sous-lieu), quatre événements, trois relations, quatre références de scène, trois commentaires et une proposition de deux opérations laissée en revue. Deux conversations avec le simulateur local.

Le projet reste disponible : http://localhost:3000/projets/0f66def9-3087-4a34-aea9-d42a2a09c36f

Les vues fusionnées et les vues lecteur/Bob sont des jeux de qualification existants, consultés sans modification. Aucune approbation/fusion, nouvelle invitation/délégation, clé réelle ou ouverture publique effectuée pour ce dossier. Aucun code applicatif modifié. Réglages d’affichage initiaux conservés ; aucune vue mobile/tablette, conformément au choix du propriétaire.

## Contenu

- INDEX.html : galerie locale, filtres, agrandissement et navigation clavier.
- SOMMAIRE.md : liste des captures par fonction.
- captures/ : 100 JPEG originaux, non retouchés.
- captures.json : légendes, parcours, dimensions et empreintes SHA-256.
- session.json : liens pratiques vers le projet de démonstration, sans cookie ni jeton.
- exemple-archive-cartographes.zip : export réel (JSON riche, Markdown et manifeste). Cette archive narrative n’est pas un réimport ni une sauvegarde d’installation.

## Lecture des images

Les vues à taille d’écran sont prioritaires pour juger les proportions. Les vues pleine page donnent le contexte et les champs supplémentaires ; certaines sont longues, et les formulaires à défilement interne ont plusieurs cadrages. Les états de chargement intermédiaires ne sont pas assimilés à des écrans terminés. Les identifiants techniques visibles font partie de l’interface actuelle.

Les nombreuses entrées dans les listes de projets/configurations/délégations viennent des qualifications antérieures : aucune de ces données n’a été supprimée pour embellir les vues. Le dossier fournit un support de discussion, pas un audit d’accessibilité ou une validation exhaustive des fonctions.

## Pistes de revue

Navigation entre projet/atelier/bible ; densité des formulaires ; accès aux actions de validation ; vocabulaire des dépendances et versions ; contraste des commandes ; contexte des commentaires ; distinction des rôles et des états de sauvegarde ; longues listes de qualification. Les numéros utiles figurent au bas de la galerie.
